# Fauna UI critique

Follow the [UI task procedure](../../../Docs/UI.md#required-review) for the applicable evidence tier and completion rules. Inspect the full frame and changed flow before reading the author's rationale. If only source is available, capture the permitted focused preview or report the missing evidence.

Assess composition, copy, artwork, contrast, fit and interaction against the requested direction and accepted reference scope. Check computed text/icon colors against the rendered fill, including hover and focus overrides. Preserve useful rules, availability reasons, accessible names and minimum hit areas.

For each finding, identify the screen/state, visible evidence, player consequence and smallest useful correction. Separate observed defects from design hypotheses. After correction, inspect fresh captures independently. Only the user's explicit choice establishes artistic approval.
