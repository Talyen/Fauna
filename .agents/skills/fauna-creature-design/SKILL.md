# Fauna creature design

Use for new creatures and substantial kit redesigns. [Creature design](../../../Docs/CREATURE_DESIGN.md) owns the detailed design criteria, budgets and implementation boundaries; read the Boss section only when relevant.

Inspect the portrait and ability images, then recommend one coherent kit faithful to their depicted actions. Keep every authored ability at exactly 1 Mana. Check caps, timing, upgrades and reachable payoffs.

Passives must be mechanically unique among current creature passives; a different name, amount or damage type alone does not establish uniqueness. Compare against current creatures, talents and Boons; explain the distinct decision, nearest overlaps, example sequence and weakness.

Every proposed passive, including brainstorming alternatives, must include exactly six total tiers: the base tier at zero stars and five upgrades through five stars. Each tier replaces the complete previous passive and must meaningfully improve its gameplay effect; wording changes alone do not count. Prefer a simple core rule that scales naturally, and check caps and rounding so every upgrade has a reachable benefit. A shared complete rule with six explicit values is sufficient when only the value changes.

Offer alternatives when requested or when a consequential unresolved choice materially changes the kit. A request to implement authorizes choosing routine details and proceeding; a request for design advice calls for a proposal. Ask only about consequential ambiguity that cannot be resolved from the request and project contracts.

Implement through existing content, execution, preview, description, save and asset owners. Preserve deterministic behavior, focused regressions and provenance in the creature reference. Use the [UI task procedure](../../../Docs/UI.md#required-review) for rendered in-game review, and the [art direction skill](../fauna-art-direction/SKILL.md) when producing assets. Distinguish implementation, artistic acceptance and measured balance.
