# Fauna creature design

Use for new creatures and substantial kit redesigns. [Creature design](../../../Docs/CREATURE_DESIGN.md) owns the detailed design criteria, budgets and implementation boundaries; read the Boss section only when relevant.

Inspect the portrait and ability images, then recommend one coherent kit faithful to their depicted actions. Compare the passive against current creatures, talents and Boons; explain its distinct decision, nearest overlaps, example sequence and weakness. Define all six complete passive tiers and keep every authored ability at exactly 1 Mana. Check caps, timing, upgrades and reachable payoffs.

Offer alternatives when requested or when a consequential unresolved choice materially changes the kit. A request to implement authorizes choosing routine details and proceeding; a request for design advice calls for a proposal. Ask only about consequential ambiguity that cannot be resolved from the request and project contracts.

Implement through existing content, execution, preview, description, save and asset owners. Preserve deterministic behavior, focused regressions and provenance in the creature reference. Use the [UI task procedure](../../../Docs/UI.md#required-review) for rendered in-game review, and the [art direction skill](../fauna-art-direction/SKILL.md) when producing assets. Distinguish implementation, artistic acceptance and measured balance.
