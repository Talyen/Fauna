# Script implementation map

[Contributing](../CONTRIBUTING.md) owns command selection and verification policy; [AGENTS.md](../AGENTS.md) owns authorization and invariants.

Implementation folders follow workflows: `agent/`, `assets/`, `balance/`, `checks/`, `ci/`, `dev/`, `performance/` and `release/`. Shared Node helpers remain in `lib/`. Worktree creation, cleanup and integration retain their root entrypoints. Use the existing npm commands from any task checkout; file moves do not change command names or verification policy.

CI orchestration and completeness are owned by [ci.mjs](ci/ci.mjs) and the [workflow](../.github/workflows/ci.yml). The gate checks exact build/run identities, all discovered browser cases, upstream job results, unit results and the seeded interaction trace. Unit totals must match the recorded passing assertions; the mixed interaction trace must contain valid actions and a checkpoint hash for every completed step. [ci-timings.mjs](ci/ci-timings.mjs) records GitHub job and step timings for a run and optional attempt; see [CI measurements](../Docs/archive/CI_SPEED_PLAN.md#baseline-and-success-measures).

Documentation parsing, measured bundle checks, worktree setup, integration safeguards and CI summary patterns are adapted from the sibling Alchemy repository. They have no runtime dependency on that checkout. Fauna retains its own command policy, save rules, worktree cleanup and release identity.

## Bundle allowance

The reviewed UI and recovery rollout baseline is 670,024 uncompressed JavaScript bytes, measured by the Windows job for `be2510d` in [hosted CI](https://github.com/Talyen/Fauna/actions/runs/39653514705) on October 21, 2026. This replaces the October 20 local baseline of 613,638 bytes. Review of the intervening source and dependency changes found intentional additions: the registered Radix Popover and its supporting primitives, full Collection creature pages, adaptive pagination, hand transfer choreography, shared surface measurement, and silent recovery. The lockfile adds only the Popover package; existing Radix dependencies are shared, and no animation framework was introduced. The allowance is now 704 KiB (about 7.6% headroom), with a warning at 95%. This measurement establishes bundle size only; that run failed type checking and the former size gate, so it does not establish browser or release acceptance. CI still measures the exact pushed commit.

The checker sums all JavaScript files recursively and rejects missing or empty entry bundles. Chunk splits do not create extra allowance. Investigate unexpected growth before raising the ceiling; update the measured baseline and reason together when intentional growth needs a new allowance. This gate measures JavaScript size, not artwork downloads, frame pacing or device performance. Run it against an existing build; creating a local build still requires an explicit request.

Dependency security is owned by [security-audit.mjs](checks/security-audit.mjs) through `npm run security:audit`. The expiring build-tool advisory exception is documented in [Contributing](../CONTRIBUTING.md#verification). [Periodic performance](../.github/workflows/performance.yml) runs the existing capture/comparison commands, including the optional compiler build. [Signed Windows candidates](../.github/workflows/release-candidate.yml) use `npm run package:installer`; see [release qualification](../Docs/RELEASE.md#candidate-signing-and-qualification).
