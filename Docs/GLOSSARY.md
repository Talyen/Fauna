# Gameplay glossary

The canonical definitions live in [src/game/glossary.ts](../src/game/glossary.ts) and are available in-game under **Menu → Glossary**. Keep terminology in card text and feedback consistent with those definitions.

Terms currently defined: Health, Block, Mana, Action card, Attack, Damage, Hit, Marks, Turn, Battle, Draw / discard, Knockout, Keyword XP, Talents, Reserves, Starting lineup, Relics, and Currency.

The seven damage types classify attacks. They do not imply elemental matchups or status effects. “Mark” is an actual stack mechanic; “Poison” is currently only reserved damage vocabulary.
