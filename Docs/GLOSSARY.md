# Gameplay glossary

Keyword definitions live in [src/game/keywords.ts](../src/game/keywords.ts); the complete gameplay glossary is assembled in [src/game/glossary.ts](../src/game/glossary.ts) and is available in-game under **Menu → Glossary**. Keep terminology in card text and feedback consistent with those definitions.

Terms currently defined: Health, Block, Mana, Action card, Attack, Damage, Hit, Marks, Turn, Battle, Draw / discard, Knockout, Keyword XP, Talents, Reserves, Starting lineup, Relics, Currency, Healing, Thorns, and each of the seven damage types.

The seven damage types classify attacks. They do not imply elemental matchups or status effects. “Mark” is an actual stack mechanic; “Poison” is currently only reserved damage vocabulary.

See [Keywords](KEYWORDS.md) for the Alchemy-derived catalog, color identity, current rules, and planned mechanics.
