# Ten artwork-led Boons

The ten Boons use the unchanged Drive PNG originals and the shared card recipe. Source identity, location and rights notes are recorded in the asset manifest. Their rule and timing contracts are in [Boon contracts](../content/boons.md#rose-and-hearth-boons).

The pre-change `boon` capture used the existing reward screen at 1280×720 with 125% text and 1920×1080 with default text. The four matching-condition new Boon groups were inspected at both sizes in the Vite browser preview with reduced motion. Portrait subjects, names, contrast, framing and whole-screen fit were visible; long names wrap without collision. The four complete captures are in:

- `reports/review/seal-boons-1-retry-03c0dfa0-8feb-4997-8d22-67c4093ae677`
- `reports/review/seal-boons-2-retry-f5c1d02b-ca2e-422e-94cd-5a5e0373c1e2`
- `reports/review/seal-boons-3-retry-24347668-1dcd-4a26-8be5-d3413d008346`
- `reports/review/seal-boons-4-retry-f80c2e8d-0702-43a0-86c9-a390b10cd4db`

The baseline is in `reports/review/ten-boons-baseline-fb0ec2a1-7aa0-4f3b-bb13-f49750acbc5e`. The first attempted capture was invalidated by a source change; a later first-group attempt failed on Vite dependency re-optimization. Those diagnostic captures are not used as evidence.

In a fresh browser preview, keyboard focus revealed Rosewax Seal's rule, Enter chose it, the journey advanced to Encounter 5, and Pause → Boons displayed Rosewax Seal with the same rule. This is browser evidence, not native desktop or physical controller verification. The focused combat suite covers the new effects, selected interactions, choice commitment and save/resume. Numerical strength has not been established by a balance sweep; compilation, broader tests and platform checks remain CI or release work.
