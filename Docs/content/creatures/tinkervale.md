# Tinkervale

Tinkervale is a village inventor. The [authored kit](../../../src/game/content/creatures/tinkervale.ts) owns its values and passive tiers. Spare Parts grants Block when an ally’s Armor is spent reducing damage. The Block is granted after the hit; a hit fully absorbed by Block does not wear Armor. Purge and other removal are not Armor spent for this passive. The inventor must be alive and deployed, and enemy Tinkervale uses the base tier.

Clockwork Bees are Consumed when played. Generated Bees belong to their creator, enter hand or ordinary overflow, recycle if unplayed, and expire after battle. They use the ordinary temporary-card capacity and save/resume rules. Ordinary enemy Tinkervale stores up to six Bees and can select one as its action; enemy cards use the same authored effects.

## Artwork provenance

The [Tinkervale portrait](https://drive.google.com/file/d/1c046eWAckNlewamk00Os2CO6XAaUmR8F/view), [Copper Canopy](https://drive.google.com/file/d/1_rZKloOOBfFscreZAJmyoat-qteqP4dA/view), [Clockwork Launch](https://drive.google.com/file/d/1j0zZrsnivVwz3Z2UZ88bcdbT03x3dw7p/view) and [Gear Mender](https://drive.google.com/file/d/1BvC0o4at7tnAIaOtJJ19lvgxnrRtPqmq/view) are selected from Google Drive. The user selected Clockwork Bee variant 2 on October 29, 2026.

The Bee was generated using the built-in image tool, the [Fauna locked art prompt](https://drive.google.com/file/d/1VODYgwwZO9leeR5xLgc5OoVdbefRiYRv/view), and Tinkervale portrait and Clockwork Launch reference images at the user's request. The user asked for no subject detail beyond “a clockwork bee”. The locked creature-card format was adapted to a 3:4 ability card; its preferred model name was requested in the prompt, but the tool does not expose a model selector.
