# Battle Swap review sample

Open `/design/battle-swap/index.html` on the development server. Add `?open=1` to open the dialog or `?open=1&ko=1` to show a knockout. Select creatures in either order to exchange them; reload resets the local fixture.

This presentation sandbox demonstrates an earlier free-swap flow. It does not advance combat or change saves. Use [journey rules](../../Docs/EXPEDITION_DESIGN.md#roster-and-battles) and [required replacement](../../Docs/ui/screens.md#encounter-and-required-replacement) for current gameplay and presentation.
