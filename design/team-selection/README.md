# Pre-battle team selection review sample

Open `/design/team-selection/index.html` on the development server. The isolated six-species fixture supports mouse and keyboard selection, roster swaps, inspection and a sample Deck; reload resets it. It does not change saves or launch combat.

The editable formation and six-species roster are specific to this fixture. Current deployment and encounter entry follow [roster rules](../../Docs/EXPEDITION_DESIGN.md#roster-and-battles).
