# Visual workflow benchmark

Use these three cases when changing the skills. Keep gameplay fixture, asset generation, viewport, text size and time/motion conditions fixed. Preserve the existing result and compare the new result without persuasive captions. A baseline is evidence of current behavior, not automatic artistic approval.

| Case                                  | Realistic request                                                                    | Evidence and success criteria                                                                                                                                                                                                                                                                                                             |
| ------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Settings: text and controls           | Make Display settings clearer and remove redundant text without changing preferences | [Current frame](references/settings-1920.png); existing labels, options, selected values and keyboard behavior retained; identify repeated section meaning before adding subtitles; stable tab geometry                                                                                                                                   |
| Merchant: artwork and choice          | Apply the user's requested Merchant composition while preserving inspection and play | [A](references/merchant-before-1280.png) / [B](references/merchant-candidate-1280.png); exact effects available through accessible inspection; restrained copy density; explicit user preference decides appearance; limit/duration/wallet clear; art ratios/profiles and hit areas retained; purchase, reload and leaving remain correct |
| Battle: dense interactive composition | Improve targeting clarity without adding permanent instructions or obscuring cards   | [Current idle frame](references/battle-1920.png); inspect an actual selected-action state before changing anything; preserve row order, six-card hand reachability, Mana, required replacements, End turn, targeting forecast and cancellation                                                                                            |

For each run, record concrete findings and fixes for composition, unnecessary copy, artwork cohesion and interaction. Count avoidable instructional/repeated phrases separately from essential gameplay rules. Do not optimize total word count by hiding useful information. Record fit and control reachability at 1280×720 with 125% text, plus the default-size comparison at 1920×1080. Present matching A/B frames for user preference; do not assign the agent's own aesthetic score.
