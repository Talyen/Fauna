# Battle rewards review sample

Open `/design/battle-rewards/index.html` on the development server. The isolated fixture walks through earnings, a recruit choice and an item choice using local presentation state; reload resets it. Names, effects and amounts are placeholders, and the fixture does not grant rewards or change saves.

The sample's choices differ from current gameplay. Use [journey rules](../../Docs/EXPEDITION_DESIGN.md#screen-flow-and-journey-results) and [reward presentation](../../Docs/ui/screens.md#victory-recruitment-and-team-replacement) for the current flow.
