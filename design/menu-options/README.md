# Menu comparison

Open `/design/menu-options/index.html` through the development server. These are presentation fixtures using the game's actual shared shadcn Button, Dialog, Switch, RadioGroup and theme tokens. Settings controls are interactive demonstrations; the other choices illustrate layout and do not navigate or change game saves.

Approved: C, with a default Button for Continue/New expedition/Resume and ghost Buttons for other choices. The live game implements this treatment. Colors use the approved pure-black, neutral-charcoal, ivory and muted-gold semantic theme. UI color values belong in `src/ui/tokens.css`.
