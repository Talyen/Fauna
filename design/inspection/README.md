# Creature inspection comparison

Open `/design/inspection/index.html` on the development server. Use the layout tabs to compare the stacked and side-by-side fixtures; `?layout=side` opens the side-by-side option and `&enemy=1` shows the enemy fixture. Thumbnails open action details, with keyboard navigation and focus return. The sandbox has local presentation state and does not change saves.

The fixture uses an older inspection layout and placeholder action artwork. The [inspection specification](../../Docs/ui/screens.md#creature-and-action-inspection) owns the current composition, disclosure and controls.
