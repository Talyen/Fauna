# Combined Settings review

Open `/design/settings-combined/index.html`. This composes the recorded choices into a playable Settings dialog rather than asking for another round of isolated choices. It renders Fauna's actual Settings, AudioSettings and setting-row compositions using the registered shadcn primitives. Theme overrides are scoped to this study; production Settings is unchanged.

Reviewed styling includes black/gold active tabs with 20px Lucide icons, 4px spacing and 12px horizontal padding; subtle inactive hover and 150ms color transitions; gold/gray switches with 150ms thumb movement; gold radio outline/dot with focus around the label; gold/gray sliders with ivory thumbs, 10% steps and whole-control focus; 150ms dialog fades over 80% black; and gray scrollbars visible on hover, focus or scrolling. Switches use a 44px hit area around a 36px track. Radio labels and slider thumbs preserve control hit areas while text changes size. Native tab/radio arrows, Tab/Shift+Tab, Space, slider Home/End, modal focus ownership and Escape remain primitive-owned.

Preview tools are explicitly separate from the proposed game settings. Narrow layout constrains the dialog to 440px; Short window constrains its height to 440px. Controls/text never shrink to fit: rows wrap, tab strips scroll and the dialog scrolls. Text and tooltip scaling update root theme variables as the actual application does, with cleanup on unmount. Preview tooltip demonstrates the chosen immediate/above/8px/100ms/neutral treatment with plain inline keywords. System and study reduced motion remove transitions and spatial effects.

Simulate save error displays a persistent synthetic notice with muted-red Lucide warning icon, ordinary light text and Retry. Retry clears only this sample notice. Settings values are ephemeral React state; no application session, game save, platform display API or player-preference persistence is used. Diagnostics is an isolated in-memory store with no real errors; its Copy action copies only that generated sample report when explicitly activated. Audio controls do not play sounds: listening/mix review remains pending. Reset preview values resets the sample controls and returns to Display; closing/reopening retains values.

This preview is for combined acceptance against [Phone decisions](../PHONE_DECISIONS.md). Full CI viewport/input journeys, native desktop, physical controller, Windows, Steam and Steam Deck acceptance remain separate and pending.

Focused local browser review checked the rendered Display/Sound compositions, native tab and radio arrows, 10% slider key changes with whole-slider focus, 150% text in the 440px-wide Sound layout without dialog-wide horizontal overflow, scrolling in the 440px-high layout, reduced-motion styles, simulated error/Retry and modal focus return. Retry restores focus to the active Settings tab; closing uses the same returnFocus owner as the application. The preview also corrects duplicate switch-thumb translation caused by combining upstream utility styles with the study's fixed-pixel track treatment. These findings are local component-preview evidence, not acceptance of the full game.
