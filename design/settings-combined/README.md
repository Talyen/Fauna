# Combined Settings review

Historical Settings sandbox. Constrained scrolling, typography and synthetic error/Retry controls below are recorded study behavior. Current [Settings](../../Docs/ui/screens.md#settings) and [recovery rules](../../Docs/UI.md#recovery-and-persistent-failures) take precedence.

Open `/design/settings-combined/index.html`. This composes the recorded choices into a playable Settings dialog rather than asking for another round of isolated choices. It renders Fauna's actual Settings, AudioSettings and setting-row compositions using the registered shadcn primitives. Switch/slider/button/dialog interaction overrides remain scoped to this study. Feedback on tabs, hierarchy, size choices, icons, audio defaults and diagnostic removal is shared with production Settings.

Reviewed styling includes centered tabs with visible neutral inactive borders, gold selected/hover borders and light active text and no background strip and with distinct 20px Lucide icons, 12px spacing and 12px horizontal padding; subtle inactive hover and 150ms color transitions; gold/gray switches with 150ms thumb movement; gold radio outline/dot with focus around the label; gold/gray sliders with ivory thumbs, 10% steps and whole-control focus; 150ms dialog fades over 80% black; and gray scrollbars visible on hover, focus or scrolling. Switches use a 44px hit area around a 36px track. Radio labels and slider thumbs preserve control hit areas while text changes size. Native tab/radio arrows, Tab/Shift+Tab, Space, slider Home/End, modal focus ownership and Escape remain primitive-owned.

Preview tools are explicitly separate from the proposed game settings. Narrow layout constrains the dialog to 440px; Short window constrains its height to 440px. Controls/text never shrink to fit: rows wrap, tab strips scroll and the content panel and preview tools scroll independently. Text and tooltip sizes offer 75%, 100% and 125%, defaulting to 100%. All audio sliders default to 50%. Text and tooltip scaling update root theme variables as the actual application does, with cleanup on unmount. Preview tooltip demonstrates the chosen immediate/above/8px/100ms/neutral treatment with plain inline keywords. System and study reduced motion remove transitions and spatial effects.

Simulate save error displays a persistent synthetic notice with muted-red Lucide warning icon, ordinary light text and Retry. Retry clears only this sample notice. Settings values are ephemeral React state; no application session, game save, platform display API or player-preference persistence is used. Diagnostic reporting and its tab/copy action are removed. Audio controls do not play sounds: listening/mix review remains pending. Reset preview values resets the sample controls and returns to Display; closing/reopening retains values.

Current hierarchy uses normal light foreground text: 24px semibold dialog title, 20px semibold section headings and 16px option labels at default size. Headers do not use gold merely for hierarchy. Inactive tabs use subtle charcoal hover fill and gold borders. Every tab has a real visible border; keyboard focus retains its outline and a visible neutral border.

Panel switches keep the dialog height and tab geometry fixed. Every tab label uses regular weight. Long panel content scrolls internally with stable scrollbar gutters; preview tools have their own bounded scroll area. Content switches instantly without fading, overlap or movement. Tab colors retain their 150ms transitions; reduced motion removes these. Native shadcn/Radix tabs own selection, visibility and focus.

Selected tabs have no extra hover change. Border thickness stays fixed; keyboard/controller focus remains visible.
