# Combined Settings review

Open `/design/settings-combined/index.html` to explore the isolated Settings fixture. Its preview tools offer narrow and short layouts, size controls and a synthetic save-error notice. Values are local presentation state; the fixture does not save player preferences, change a session or play audio.

The fixture retains an earlier dialog and synthetic Retry control. Current [Settings](../../Docs/ui/screens.md#settings), [shared UI contracts](../../Docs/UI.md) and [recovery rules](../../Docs/UI.md#recovery-and-persistent-failures) own the production behavior.
